# HCA200 Chapter 3 Study Arcade

A static, mobile-friendly practice site with six game modes, immediate explanations, topic filters, a retry queue, and on-device progress tracking.

## Files

- `index.html` — app shell
- `styles.css` — responsive layout and visual styles
- `data.js` — question bank and source locators
- `app.js` — navigation, game sessions, feedback, scoring and local progress
- `CONTENT_NOTES.md` — content scope, source map and verification notes

## Run locally

Open `index.html` in a modern browser. No build step, server, account, or external library is required.

## GitHub Pages

1. Add these files to the root of a GitHub repository.
2. In repository settings, open **Pages**.
3. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
4. GitHub Pages will provide the cohort URL when the deployment finishes.

The site does not transmit learner data. Scores and retry status are kept in the browser's local storage on the current device.

## Important source note

The user-requested full Chapter 3 textbook text was not attached to the referenced chat or found in the available files. The app is therefore transparently based on the 26-slide HCA200 Workplace Setting deck and instructor-derived HCA200 study notes available locally. See `CONTENT_NOTES.md` and the in-app Source notes page before cohort sharing.
