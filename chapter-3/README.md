# HCA200 Chapters 2 & 3 Study Arcade

A static, mobile-friendly practice site with eight game modes, 104 questions, immediate teaching explanations, chapter and topic filters, a retry queue, and on-device progress tracking. Teresa’s Chapter 2 quiz-review cues are emphasized throughout the health-system and care-pathway questions.

## Files

- `index.html` — app shell
- `styles.css` — responsive layout and visual styles
- `data.js` — question bank and source locators
- `app.js` — navigation, game sessions, feedback, scoring and local progress
- `CONTENT_NOTES.md` — content scope, source map and verification notes

## Run locally

Open `index.html` in a modern browser. No build step, server, account, or external library is required.

## GitHub Pages

The files can be served from a repository root or a subfolder. Enable GitHub Pages for the repository and branch containing these files.

The site does not transmit learner data. Scores and retry status are kept in the browser's local storage on the current device.

Chapter 2 uses the full textbook text, slides and Teresa’s review cues. Chapter 3 uses the Workplace Setting slide deck, class notes and Teresa’s review cues. The full Chapter 3 textbook text was unavailable for line-by-line verification; see `CONTENT_NOTES.md` and the in-app Source notes page.
